# maxvec

**Maximal graded subalgebras of simple vectorial Lie superalgebras with polynomial coefficients**

D. Leites, I. Shchepochkina. Status: in preparation.

The scripts check the computed claims of the text: the case 1° for the contact algebras
k(1|2n) (n = 2, 3, 4); the multiplicity-one property of the brackets on g_- for the ambients of
depth > 1; the subalgebra u_0 of sl(2^k|2^k) behind the exclusion of the superdimension 1+eps;
the maximality of le(n)+C.E in vect(n|n) and of sle(n)+C.E in svect(n|n); the dimension test of
the regraded components g_0; the inclusion order of the depth-1 entries of table (65); and the
formulas of Section 2 for the brackets and divergences of K_f, H_f, M_f, Le_f. Exact arithmetic
over Q throughout (fractions, integers, and `../lib/exactlin.py`, fast when python-flint is
installed and correct without it).

## How to run

```bash
python3 -m venv venv && venv/bin/pip install -r maxvec/requirements.txt
cd maxvec
../venv/bin/python depth.py
```

Every script is run from inside this folder; it finds `../lib/exactlin.py` by itself. Output goes
to stdout. Running times are wall-clock times on a laptop; runs not listed with a time take under
a minute.

## Files

- `vf.py`, `sub.py` — polynomial vector fields; u_{-1} and u_0 of vect(m|n+k;k) inside sl(2^k(m|n)).
- `lattice2.py`, `irr.py`, `prol2.py` — the submodules of sl(W)/u_0, the intermediate
  subalgebras, their Cartan prolongs (arguments `m n k [degree]`).
- `regraded_dims.py` — the dimensions of the components of k(1|2n;n) and m(n;n).
- `kcase1.py` (argument: the values of n), `kgen.py`, `k14.py` — the contact algebras k(1|2n).
- `depth.py` — multiplicities by Freudenthal's formula, exact.
- `wgrad.py` — polynomial vector fields, the series vect, svect, h, k, m, le; library.
- `run_cartan.py` — Cartan prolongs of linear Lie superalgebras on small V; library for the
  other `run_*.py` (its own main runs the small cases).
- `run_prolong.py` (argument: the values of n), `run_maxgl.py` (argument: the values of n),
  `run_case3.py` (arguments: `[--kmax K] ne no ...`), `run_case3b.py`, `run_pairs.py`
  (`[--kmax K]`), `run_regrad.py`, `check_spe.py` — Section 9.
- `contact.py`, `kbracket.py`, `mbracket.py`, `kdiv.py` — the formulas of Section 2.
