# super-public

Programs behind the computed claims of papers by D. Leites, O. Lozhechnyk and co-authors on
Lie (super)algebras. One folder per paper; each folder has its own README with a table
"claim in the text -> script -> expected output". Shared exact linear algebra is in `lib/`.
License: MIT (see `LICENSE`).
