# kaehler

**Superization of Kähler and hyper-Kähler manifolds**

D. Leites. Status: in preparation.

The scripts compute, in the flat local model of the text (Subsec. 1.5: operators on
(pseudo-)differential forms on the flat superspace C^{a|b}, written in a super Weyl algebra
with exact rational coefficients, odd parameters hbar adjoined as odd central generators),
the Lie superalgebras generated by the invariant operators of a (hyper-)Kähler or periplectic
structure: multiplication by the 2-forms and convolution with the dual bivectors, the
differentials d, d_c = J d J^{-1} and their twists by connections whose curvature is
proportional to omega. They also compute the Cartan prolongs and the Spencer cohomology
H^2(g_-; g_*) of the Appendix (pairs of forms), and the normal shapes of a pair of
non-degenerate forms on a superspace. Exact arithmetic throughout (`fractions`, and
`../lib/exactlin.py`, fast when python-flint is installed and correct without it).

## How to run

```bash
python3 -m venv venv && venv/bin/pip install -r kaehler/requirements.txt
cd kaehler
../venv/bin/python check_odd.py
```

Every script is run from inside this folder, with no arguments; it finds `../lib/exactlin.py`
by itself. Times below are on a laptop under no other load. `conj2.py`, `conj2c.py`,
`conj2d.py`, `conj2e.py` run their whole computation when imported, so every script that
imports them (`conj2f.py`, `mixed2.py`, `mixed3.py`, `evenJ.py`, `derived.py`) prints
their output first and takes correspondingly longer.

## Known defect (to be corrected together with the text)

`contact.py`, function `gl_stab`, solves X B + B X = 0 instead of X^T B + B X = 0 for the
stabilizer g_0 of the pair (B_1, B_2). For diagonal J the two give spaces of the same dimension
and the same H^2 (the rows n = 1 and generic J are right), but not otherwise. Solved with the
correct equation, which is the one of the proof of Lemma 6.4.1 (conditions (X)):

- n = 2, J one Jordan cell: dim g_0 = 2 (not 1), torsion 16, curvature 2 (not 20 and 0);
- n = 2, Kähler pair: torsion 8, curvature 9 (not 8);
- n = 3, Kähler pair: torsion 36, curvature 36 (not 30).

The curvature of the Kähler pair is (n(n+1)/2)^2, the dimension of the space of Kähler curvature
tensors, as it should be. So table (Hcase1) of Theorem 6.4.3 and the remark after it (a single
Jordan cell has dim g_0 = 1 and no curvature) inherit the defect.

## Files

- `flatmodel.py` — the flat model: the super Weyl algebra on the coordinates and their
  differentials, closure of a set of operators, the exterior differential.
- `check_classical.py`, `check_odd.py` — the four parity cases of (J, h) and the hyper-Kähler
  cases (Remark 4.1, Proposition 1.7.6, Theorems 3.3.3, 3.3.5).
- `derived.py` — the derived series of Theorem 3.3.5.
- `conj2.py`, `conj2c.py`, `conj2d.py`, `conj2e.py`, `conj2f.py` — the twisted algebras of
  Theorems 1.8.2 and 3.2.1 (`conj2.py` also provides span/centre/derived helpers).
- `curv.py`, `twohbareven.py`, `twdelta.py` — the two connections and the twisted Laplacian.
- `poletaeva.py` — Remark 3.2.2.
- `laplace.py` — the odd Laplacian of Subsec. 1.9.
- `mixed.py`, `mixed2.py`, `mixed3.py`, `evenJ.py` — Theorem 1.9.3.
- `check_Dminus.py`, `check_split.py` — Theorem 1.9.4a.
- `twohbar.py` — Theorem 1.9.6.
- `halves.py`, `halves_sdim.py` — Lemma 1.10.1, Example 1.10.2.
- `pairs.py`, `normshape.py` — Subsec. 6.3 and Lemma 6.4.1.
- `contact.py` — Subsecs. 6.4 and 6.5.
