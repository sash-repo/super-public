# borcmod

**Unary and binary osp(n|2)-invariant differential operators on the 1|n-dimensional contact
supermanifold in characteristic >2**

S. Bouarroudj, D. Leites, O. Lozhechnyk. Status: in preparation.

The scripts compute, over the prime field F_p, all linear and bilinear maps between spaces of
weighted densities on the contact superdomain of superdimension 1|n (n = 1, 2) that are invariant
under osp(n|2) or under the whole contact algebra k(1;N|n); the functions are divided powers
O(1;N|n), with shearing vector N and P = p^N. Exact arithmetic mod p for the censuses (via
`../lib/exactlin.py`), sympy over Q for the symbolic identities.

## How to run

```bash
python3 -m venv venv && venv/bin/pip install -r requirements.txt
cd borcmod
../venv/bin/python kfull.py 5 1
```

Every script is run from inside this folder; it finds `../lib/exactlin.py` by itself. The
arguments `p N` are the characteristic and the shearing vector; weights run over F_p. Scripts
marked "two steps" read the output of another script from a file.

## Files

- `osp1.py` — O(1;N|1), the generators of osp(1|2) and k(1;N|1), the equivariance solver (unary, n=1).
- `kfull.py` — Proposition 5.3 against its closed form; Theorem 5.4.
- `osp2.py` — O(1;N|2), K_f, osp(2|2), the equivariance solver (unary, n=2); `python3 osp2.py p N`
  also searches the multipliers among three candidates.
- `cocyc2.py`, `explicit2.py`, `closed2.py`, `kfull2.py`, `ident2.py`, `ccheck2.py` — Section 6.
- `bin1.py`, `binnum.py`, `bindef_lib.py`, `binred.py`, `bindef.py`, `binpred.py`, `binkfull.py`,
  `binkbrute.py`, `bincomp.py` — Section 7 over F_p.
- `binsym.py`, `binC.py`, `binop.py`, `binJk.py`, `binJg.py`, `binJ3.py`, `binCm1.py` —
  Section 7 symbolically (sympy).
